# 無料ボイスメモ文字起こし

登録不要・完全無料で使えるボイスメモ文字起こしツールです。`index.html` 1ファイルだけで動きます。

## 使い方

1. `index.html` を **Google Chrome / Microsoft Edge / Safari** で開く
2. 「● 録音開始」を押してマイクを許可し、話す
3. 「■ 停止」を押す
4. 「⬇ テキストをダウンロード (.txt)」で文字起こしを保存（音声も保存できます）

## 機能

- リアルタイム文字起こし（日本語・英語・中国語・韓国語）
- 時刻付きで記録、テキストは手で修正可能
- テキスト (.txt) ダウンロード／コピー
- 録音した音声のダウンロード
- 入力内容はブラウザに自動保存

## 補足

- 音声認識にはブラウザ標準の Web Speech API を使っています。Chrome / Edge では認識のために音声がブラウザ提供元のサーバーへ送られます。
- Firefox は音声認識に対応していません。
- GitHub Pages を有効にすると、スマホからも URL で使えます（Settings → Pages → Branch を選択）。
